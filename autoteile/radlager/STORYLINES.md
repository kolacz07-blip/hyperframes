# Radlager – drei Storylines

**Gewählt: A „Das Brummen“.**

## A: „Das Brummen“ (gewählt)

Eine einzige Kamerafahrt: Low-Poly-Auto auf der Landstraße bei Sonnenuntergang → Brummen setzt ein → Kamera taucht durch die Radkappe ins Radlager → Aufbau, Explosionsansicht, Schaden (Schlagloch, Wasser, Rost, Fett, Metall auf Metall) → Symptome (Brummen, Spiel, Hitze, ABS-Leuchte) → Lager blockiert → zurück zum Auto → „Brummt's? Ab in die Werkstatt“.

## B: „Die Explosionszeichnung“

Ein Low-Poly-Rad auf heller Bühne baut sich Teil für Teil auf und geht danach vor deinen Augen kaputt. Technisch-sauber, Signalfarben.

## C: „Die Straße aus Schall“

Die Brumm-Schallwelle wird zu einem Low-Poly-Gebirge, über das das Auto fährt; je kaputter das Lager, desto zackiger die Berge. Neon-Typo im Takt.
